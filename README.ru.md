# Варианты для Claude Code

[English](README.md) | Русский

Когда фичу или исправление бага можно сделать несколькими разумными способами, Claude обычно описывает варианты текстом в чате, а код появляется только у выбранного. Этот мод выкладывает варианты рядом на странице в браузере: у каждого суть, плюсы и минусы, затронутые файлы и настоящий дифф. Их можно сравнить, скомбинировать, обсудить и применить, не уходя со страницы.

Страница построена на [Claude Hub (webhub)](https://github.com/jabenb/claude-webhub): хаб её хостит, держит в актуальном состоянии и передаёт ваши нажатия обратно в сессию.

## Что на странице

- **Задача**: баг или фича, тикет, что не так или что нужно, для бага — как это происходит по шагам.
- **Карточки вариантов**: по одной на вариант, рекомендованный Claude отмечен; добавленные и удалённые строки — когда код уже получен.
- **Вариант подробно**: суть подхода, плюсы и минусы, затронутые файлы бейджами (`A` новый, `M` изменён, `D` удалён) со строкой о том, что меняется в каждом, и блок кода.
- **Три уровня детализации**, каждый следующий — только по нажатию: описание (есть всегда), **Набросок** (короткий псевдокод по файлам) и **Показать код** (точный дифф).
- **Код**: дифф в одну колонку или бок о бок, либо весь файл с изменениями (тоже в одну колонку или бок о бок), с подсветкой Islands Dark. Длинные куски без изменений свёрнуты. Клик по номеру строки добавляет ссылку на неё в чат.
- **Обсуждение**: чат с Claude прямо на странице.

## Что можно делать

| Действие | Что происходит |
|---|---|
| **Набросок** | Короткий псевдокод по файлам: какие классы и методы появляются и ключевая логика. Дёшево; хватает, чтобы оценить вариант. |
| **Показать код** | Точный дифф. Запрашивается только по нажатию; если есть набросок, код пишется в его русле. |
| **Выбрать вариант X**, затем **Применить** | Для применения нужен код: у выбранного варианта без кода сначала кнопка **Получить код**, чтобы вы увидели дифф до записи. Мод сам записывает файлы варианта, модель не участвует. Если файл на диске изменился с момента предложения, ничего не записывается, а страница предлагает получить код заново. Claude узнаёт о применённом варианте вместе с вашим следующим сообщением. |
| **Скомбинировать** | Для каждого файла выбираете, из какого варианта его взять. Сборка запрашивает код у выбранных вариантов, где его нет, потом новый вариант собирается на странице без модели; простая проверка по именам файлов предупреждает, если файл опирается на новый файл своего варианта, который вы не взяли. Галочка **Проверить стыки с Claude** отдаёт сборку Claude на проверку и правку стыков. |
| **Другой вариант** | Попросить у Claude ещё один вариант с ограничениями («без миграций», «минимум изменений», …) и пожеланием. Он появится новой карточкой. |
| **Своё решение** | Описать своё решение, вставить его код — Claude оценит его по коду и, если стоит, добавит вариантом. |
| **Вопрос** | Спросить про вариант или про строку. |

## Минимум токенов

Мод держит подальше от модели всё, что может:

- **Варианты приходят без кода**, со строкой о том, что меняется в каждом файле. Сам по себе ничего не запрашивается: набросок или код — только по нажатию кнопки. Вариант, который вы только прочитали, не стоит лишних токенов.
- **Наброски и код пишет fork сессии**: он не появляется в чате и переиспользует кэш сессии. Claude присылает правки в стиле Edit (`old → new`), а не файлы целиком; мод проверяет каждую правку по файлу и собирает результат. Если ответ не сошёлся, есть ещё одна попытка с текстом файла, потом код пишет сама сессия.
- **Диффы, счётчики строк, подсветка, сборка и применение** делаются модом и страницей.
- **Вопросы** по умолчанию идут в маленький контекст, который собирает мод (задача, варианты, изменения спрошенного варианта, строки, на которые вы сослались, последние реплики чата); отвечает `sonnet` с низким effort. Кнопка **Спросить с полным контекстом** под ответом спрашивает fork сессии.
- Через сессию идёт только то, чему нужны код и инструменты: другой вариант, своё решение, проверка стыков. Ответ этого хода возвращается в чат страницы. Пока Claude занят ходом, такие сообщения ждут в очереди и уходят, когда ход закончится.

## Тесты после «Применить»

Вариант может назвать тесты, которые его покрывают. Если установлен мод тестов, который даёт `$.tests`, рядом с **Применить** появляется галочка **Прогнать тесты варианта**: тесты запускаются через этот мод без модели, а страница показывает результат и ссылку на страницу тестов. Без такого мода галочка скрыта.

## Требования

- [Claude Hub (webhub)](https://github.com/jabenb/claude-webhub) в том же scope и Docker для его сервера.
- Сессия запущена там, где лежат файлы проекта: мод их читает и записывает при «Применить».
- Сборка Claude Code с поддержкой модов (плагины с hooks-модулем).
- Браузер с доступом в интернет для подсветки кода. Без него страница работает, код показывается без цветов.

## Установка

Моду нужен [Claude Hub (webhub)](https://github.com/jabenb/claude-webhub): ставьте оба в одном scope. Scope определяет, где они работают:

| Scope | Где работает | Куда записывается |
|---|---|---|
| `user` (глобально, по умолчанию) | во всех проектах | `~/.claude/settings.json` |
| `project` | в этом репозитории, у всех, кто его клонирует | `<проект>/.claude/settings.json` |
| `local` | в этом репозитории, только у вас | `<проект>/.claude/settings.local.json` |

### Глобально

```bash
claude plugin install webhub --marketplace jabenb/claude-webhub
```

```bash
claude plugin install variants --marketplace jabenb/claude-variants
```

В строке ввода сессии Claude Code то же самое: `/plugin install variants --marketplace jabenb/claude-variants`.

### Для одного проекта

Запускайте из папки проекта с `--scope project` (или `--scope local`, чтобы настройка не попала в файлы, которые видят другие):

```bash
cd ~/path/to/project
```

```bash
claude plugin install webhub --marketplace jabenb/claude-webhub --scope project
```

```bash
claude plugin install variants --marketplace jabenb/claude-variants --scope project
```

### Из локальной копии

Чтобы запустить клон или свои изменения без GitHub, добавьте папку как маркетплейс и поставьте из неё (в любом scope выше):

```bash
git clone git@github.com:jabenb/claude-variants.git ~/claude-variants
```

```bash
claude plugin marketplace add ~/claude-variants
```

Глобально:

```bash
claude plugin install variants@claude-variants
```

Или для одного проекта, из его папки:

```bash
claude plugin install variants@claude-variants --scope project
```

Хаб ставится так же из своего клона (`claude plugin marketplace add ~/claude-webhub`, затем `claude plugin install webhub@claude-webhub`) или с GitHub, как выше.

Во время работы над самим модом загружайте его прямо из папки на одну сессию, рядом с папкой хаба; изменения подхватываются по окончании хода:

```bash
claude --plugin-dir ~/claude-webhub --plugin-dir ~/claude-variants
```

Или для всех сессий: добавьте папку в `CLAUDE_CODE_PLUGIN_DIRS` (пути через `:`) в `env` файла `~/.claude/settings.json`. Не держите одновременно копию из папки и установленную, иначе мод загрузится дважды.

### Обновление

```bash
claude plugin marketplace update claude-variants
```

Потом начните новую сессию.

## Как пользоваться

1. Попросите Claude: «предложи варианты реализации …». Claude вызывает инструмент `propose` только по такой просьбе и одной строкой сообщает, что варианты на странице, с её адресом.
2. `/variants` в любой момент печатает адрес страницы. Хаб тоже показывает страницу под именем сессии.
3. Открывайте варианты, сравнивайте, спрашивайте, комбинируйте, выбирайте и применяйте.

## Настройки

- `VARIANTS_CHAT_MODEL`: модель для быстрых ответов в чате (по умолчанию `sonnet`), например `haiku`, чтобы тратить ещё меньше.

## Языки

Страница следует языку, выбранному в хабе: английский, русский или украинский. Сообщения, которые страница отправляет Claude, на том же языке.

## Где хранятся данные

Всё лежит в `~/.claude/mods-data/variants/sessions/<id сессии>.json` (внутри `$CLAUDE_CONFIG_DIR`, если он задан): задача, варианты с кодом, чат. В репозитории проекта не появляется ничего, кроме файлов, которые вы применили. Хаб хранит и свою копию состояния страницы.

## Для Claude

Три инструмента:

- `mcp__variants__propose`: показать задачу и её варианты, без кода. Только когда пользователь просит варианты.
- `mcp__variants__add_variant`: добавить один вариант, когда его попросила страница; код по желанию.
- `mcp__variants__variant_code`: дать код варианта, когда странице не удалось получить его самой.

## Разработка

```bash
claude plugin validate .
```

```bash
claude plugin test .
```

- `hooks/model.ts`: разбор входа, наложение правок на файлы, построчный дифф, сборка, промпты и сообщения (чистые функции).
- `hooks/register.ts`: движок и хаб: инструменты, цикл прослушивания, очередь кода, нажатия, файлы, ходы сессии.
- `hooks/page/page.ts`: вся страница; `hooks/page/theme.ts`: Islands Dark.
- `types/`: состояние и необязательный noun `$.tests`.
- `tests/variants.test.ts`: модель и мод целиком, с хабом и движком в памяти.

## Удаление

```bash
claude plugin uninstall variants
```
